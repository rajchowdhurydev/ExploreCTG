# Explore Chattogram (ExploreCTG)

**Explore Chattogram** is a frontend-based tourism and travel planning web application designed to help travelers discover popular destinations in Chattogram, explore travel information, find local guides, plan itineraries, and estimate travel budgets.

The project was developed as an academic project using **HTML5, CSS3, Vanilla JavaScript, and local JSON data** without relying on external APIs.

## 🌴 Project Overview

ExploreCTG provides a simple platform where users can explore Chattogram's tourist attractions and access useful travel information from a single website.

The application focuses on:

* Discovering tourist destinations
* Viewing detailed destination information
* Finding available local guides
* Creating a personal travel itinerary
* Estimating an approximate travel budget
* Traveler and guide dashboards
* Basic user registration and login functionality
* Responsive and user-friendly interface

## ✨ Features

### 🗺️ Destination Explorer

* Browse tourist destinations in Chattogram
* View destination images and descriptions
* Explore detailed information about individual locations

### 👨‍🏫 Guide System

* Browse available local guides
* View guide profiles
* Access guide-related information through the guide section

### 💰 Budget Estimator

* Estimate approximate travel expenses
* Calculate transportation and other basic travel costs
* Helps users plan trips according to their budget

### 📅 Itinerary Planner

* Create and manage a personal travel itinerary
* Organize selected destinations for a planned trip

### 🔐 User Authentication

* User registration
* User login
* Basic authentication using browser LocalStorage

### 👤 Dashboards

* Traveler dashboard
* Guide dashboard
* Guide profile management

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/rajchowdhurydev/ExploreCTG.git
```

2. Open the project folder:

```bash
cd ExploreCTG
```

3. Open `index.html` in a web browser.

For the best experience, run the project using a local development server such as **VS Code Live Server**.

## 📌 Project Limitations

This is a frontend academic project and therefore has some limitations:

* No real backend server
* No external database
* No online payment system
* No external map or tourism API
* Authentication is handled using browser LocalStorage
* Travel costs and destination information are based on locally stored project data
